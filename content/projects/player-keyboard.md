**Medium:** Steel Wire, Motor, Solder, Goodwill Keyboard

In this piece, I wanted to capture an unfortunately common part of my life: uncertainty, specifically with email writing. Every time I try to start a new email, I always get stopped by the first line. Do I start with a casual “hey”? Do I go for a more formal address with “dear”?

With Player Keyboard I used a series of cams and levers to mechanically program my uncertainty. This piece is doomed to forever type “hey” then delete it and write “hi” instead before deleting it all again. The keyboard never actually gets to the main content of its message. This is my best self portrait.
